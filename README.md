# SOUL PARADE

`JATA KILLER BEES`の公式B面として企画された、独立タイトルの縦画面ブラウザゲームです。

## Local play

`index.html`をブラウザで開くか、このディレクトリを静的HTTPサーバーで配信します。

- iMac: `index.html`を直接開いて試遊できます。
- スマホ実機: Tailscale接続後に `http://100.82.86.8:4173/` を開きます。
- スマホ試遊中は、iMac側で `python3 -m http.server 4173 --bind 0.0.0.0` を起動しておきます。

## Source policy

- `JATA KILLER BEES`本体は変更しません。
- 旧CROWD RUSH神話版は参照元として残し、このフォルダから上書きしません。
- `docs/SOUL_PARADE_PLAN_V1.md`を本作の企画・実装基準とします。
- `docs/PROTOTYPE_V2_SPEC.md`は、TERU提供の企画書とプロトタイプv2の保全メモです。
- `docs/ASSET_WISHLIST.md`に、今後差し替えたい手描き素材を優先度順で記録します。
- Stage 5「万神冥界市」は、原寸PNGを保全したうえで軽量WebPをゲーム表示に使用します。
- Stage 6「輪廻の塔」と首なし武者は、Nano banana2版の原画を保全したうえで軽量WebPをゲーム表示に使用します。
- Stage 3「忘却の川」のピン抜きは、専用の冥界水路塔背景 `assets/backgrounds/pin-puzzle-tower.webp` とCanvasアニメーションを組み合わせます。
- 味方魂はフィールド、隊列、ボスに捕らわれた魂、眠る魂、輪廻の塔、ピン抜き、冥界市、エンディングまで `assets/characters/little-soul-teru-v2.webp` に統一します。
- 鬼火の数字札、冥界蛾モブ、落石、ピン抜きの重りもイラストを主表示とし、Canvas図形は演出と画像読込失敗時の代替だけに使用します。
- 魂喰らい、死神、閻魔、主人公魂、鳥居、鬼火悪霊はNano banana2版へ統一済みです。集める味方魂は、TERU手描き原案の縦長の火のしずく型を同じピクセルアート表現へ整えた専用版を採用しています。旧味方魂も参照用に保全しています。
- 赤提灯・石灯籠を提灯チェックポイントへ、TERU手描き原案の小さい魂を救出対象・隊列の仲間・ピン抜きの救出魂・万神冥界市の友好的な住人へ使用しています。
- 鳥居の額文字はステージに応じてゲーム側で描画し、額の中心へ3文字を均等配置して同じ素材を各門へ再利用します。
- エンディングは徳灯（救出・提灯・選択・試練・損失）で「万灯の夜明け」「光の門へ」「黄昏の再出発」の3段階に分岐し、灯火の別れの選択も本文へ反映します。
- JATA ARCADE共通上端メニューを同梱し、埋め込み時も `GAMES` と全画面（iPhoneは別ウィンドウ）を利用できます。
- 本番公開は、独立GitHubリポジトリと独立Vercelプロジェクトを用意してから行います。

## Controls

- 画面をなぞる: 移動
- 隊列ボタンをタップ: 縦一列／円陣／散開
- 試練画面をタップ: 数字・閂・天秤・太鼓・通行印・審判を操作
- ピン抜き: 左右のリング把手を順にタップし、水・落石・重り・魂を流す
- iPhone/iPadの連続タップ、ダブルタップ、ピンチ操作によるブラウザ拡大は抑止しています。
